# Security Policy

## Reporting

Do not disclose security vulnerabilities publicly before they have been assessed and addressed.

Report suspected vulnerabilities privately to the repository maintainers.

## Secrets

Never commit API keys, passwords, access tokens, private keys, `.env` files containing secrets, or production credentials.

## Autonomous operations

AI agents must operate within explicit permissions. High-risk actions such as destructive repository operations, credential changes, production changes, or irreversible data operations require human approval.
